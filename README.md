# ShobdoLipi Keyboard (v1.1.0)

**ShobdoLipi** is a lightweight, high-performance Windows desktop application designed for seamless Unicode Bengali typing. Built using native C++ and Win32 API, it delivers instantaneous response times with near-zero background resource usage.

---

## ✨ Key Features

* **Native Performance:** Built with lightweight C++ and Win32 low-level hooks for zero input latency.
* **Instant Mode Switching:** Toggle smoothly between English and Unicode Bengali typing modes anytime with **F12**.
* **Precise Unicode Engine:** Uses direct UTF-16 escape code mapping to eliminate character rendering issues and compiler encoding bugs.
* **Tray & Splash Interface:** Runs unobtrusively in the system tray with status tooltips and a modern startup splash screen.
* **Auto-Start Support:** Option to run automatically on Windows startup.

---

## 🖥️ System Compatibility

* **Operating System:** Windows 7 (SP1), Windows 8, Windows 8.1, Windows 10, and Windows 11
* **Architecture:** Supports both 32-bit (x86) and 64-bit (x64) systems
