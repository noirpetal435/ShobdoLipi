# ShobdoLipi v1.0 - Unicode Bengali Typing App

**ShobdoLipi** is a lightweight and user-friendly Unicode Bengali typing software designed for Windows.

### ✨ Key Features
* **Unicode Typing:** Type seamlessly in Bengali across web browsers, text editors, and social media platforms.
* **Bijoy Layout Support:** Integrated support for the familiar Bijoy keyboard layout.
* **Single Installer:** Fast and hassle-free setup via a single standalone installer file.
* **Auto Shortcuts:** Automatically creates shortcuts on your Desktop, Windows Start Menu, and Startup folder for instant access upon system boot.

---

### 📥 How to Install & Use
1. Download **`ShobdoLipi.Setup.exe`** from the **Assets** section below.
2. Double-click the downloaded setup file and follow the on-screen instructions to complete installation.
3. Launch **ShobdoLipi** and start typing in Bengali effortlessly!
